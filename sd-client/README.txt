SD-Client — модифікований клієнт DDNet (Windows 10/11 x64)
==========================================================

ЗАПУСК
  1. Розпакуйте SD-Client-Complete.zip в будь-яку папку (не запускайте з архіву).
  2. Запустіть SD-Client.exe подвійним кліком.
  3. Головне меню -> Налаштування (Settings) -> вкладка "SD-Client".
  Нічого встановлювати не потрібно: всі DLL лежать поруч з exe (SD-Client.exe,
  *.dll, папка data/). Не переносіть exe окремо від data/ та DLL.

СУМІСНІСТЬ
  Клієнт використовує мережевий протокол оригінального DDNet і підключається
  до звичайних серверів DDNet. SD-Client нічого додатково не відправляє на
  сервер: усі функції лише читають дані, які сервер і так надсилає.

ФУНКЦІЇ (вкладка SD-Client у налаштуваннях)
  General        — головний перемикач, список консольних команд, скидання.
  Above / Below  — показує, чи інший гравець ВИЩЕ (Above ⋀), НИЖЧЕ (Below ⋁)
                   або на тій самій висоті. Вісь Y у DDNet спрямована вниз,
                   тому "вище" = менша координата Y. Сповіщення при зміні
                   (окремо для above/same/below), позиція X/Y, розмір, колір,
                   допуск "та сама висота", вибір конкретного гравця.
  Profiles       — необмежена кількість профілів (ім'я, клан, скін, кольори
                   тіла/ніг, прапор, емоція). Створення, зміна, видалення,
                   завантаження, превʼю скіна, збереження у
                   <папка даних>/sd-client/profiles.json.
                   Швидке перемикання: sd_profile <ім'я>, sd_profile_next,
                   sd_profile_prev (можна бінд на клавішу).
  Custom Fonts   — імпорт TTF/OTF (вставте повний шлях до файлу і натисніть
                   Import, або покладіть файл у папку sd-client/fonts через
                   кнопку "Open fonts folder" і натисніть "Refresh list"),
                   превʼю, вибір основного шрифту, повернення до стандартного.
                   Вибір зберігається між запусками.
  Anti-Ping      — показ поточного пінгу, його зміни, графіка, сповіщення про
                   високий пінг з порогом, діагностика (мін/сер/макс, джитер,
                   запас передбачення). Також виставлені справжні налаштування
                   DDNet antiping-prediction (впливають лише на відображення).
                   Реальна затримка НЕ змінюється і значення не підроблюються.
  Player Info    — у таблиці гравців (Tab) натисніть на гравця: Copy Name /
                   Clan Tag / Skin / Skin Color / Full Player Info. Також
                   команди sd_copy_name|clan|skin|skin_color|full [id] — без
                   id копіюється гравець під прицілом (зручно для bind).
                   Після копіювання зʼявляється "Copied to clipboard!".
  Hook / Hit     — сповіщення про хук (свій/чужий), потрапляння хуком по
                   гравцю, удари молотком (свої/чужі). Режими: Custom, Only my
                   hooks/hits, Only others' hooks/hits, Everything. Тривалість,
                   розмір, кольори, позиція, кількість рядків.
                   Дані — лише зі снапшотів гри (стан хука, ticks атаки,
                   справжні події HAMMERHIT). "Удар" = удар молотком.
  Grenade        — траєкторія гранати, коли в руках гранатомет: той самий
                   розрахунок позиції, що й у снаряда (швидкість, кривизна,
                   тривалість з tune-зони) і зіткнення з картою. Граната
                   вибухає при ударі (відскоку немає). Колір, прозорість,
                   товщина, маркер точки влучання.

  Кнопки "Save settings" і "Reset this section" внизу вкладки. Налаштування
  також автоматично зберігаються при виході з гри.

ВІДОМІ ОБМЕЖЕННЯ
  * Траєкторія не враховує зупинку гранати на гравцях — лише карту/час життя.
  * Користувацький шрифт змінює основний шрифт усього інтерфейсу і гри;
    гліфи, яких немає в шрифті, беруться зі стандартного.
  * Профілі застосовуються до основного гравця (не до dummy).
  * Попередні перегляди шрифтів завантажують файл у памʼять при першому показі.

ЯК ЗІБРАТИ САМОМУ (необовʼязково)
  Visual Studio 2022 (C++), CMake, Rust (rustup), Python 3, Git:
    git clone --depth 1 https://github.com/ddnet/ddnet-libs ddnet-libs
    mkdir build && cd build
    cmake -A x64 -DCMAKE_BUILD_TYPE=Release -DSERVER=OFF -DTOOLS=OFF -DVIDEORECORDER=OFF ..
    cmake --build . --config Release --target DDNet
  Готовий exe (DDNet.exe) перейменуйте в SD-Client.exe, поруч покладіть
  *.dll з папки збірки та папку data/ з вихідників.
